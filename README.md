# Part 1: Neural Network Analysis — Customer Churn Prediction

## Dataset
`customer_churn_nn.csv` — 2000 customer records, 16 features, binary churn target.

## Objective
Build and analyze a feed-forward neural network to predict customer churn.

## Tasks Covered
1. Dataset Understanding
2. Data Preprocessing (encoding, scaling, train/test split)
3. Neural Network Model Building (Keras/TensorFlow)
4. Training and Evaluation (confusion matrix, classification report)
5. Hyperparameter Experimentation (7 configurations compared)
6. Final Reflection

## How to Run
1. Open `notebook.ipynb` in Google Colab
2. Upload `customer_churn_nn.csv` when prompted
3. Run all cells in order
